# Sistema de Inclusión

## 📌 Descripción
Aplicación orientada a la gestión de información relacionada a inclusión social. Permite organizar y administrar datos de usuarios.

## 🚀 Tecnologías
- PHP
- MySQL
- HTML
- CSS

## ⚙️ Funcionalidades
- Registro de usuarios
- Gestión de datos
- Conexión a base de datos
- Operaciones CRUD

## 🧠 Aprendizajes
- Conexión entre frontend y backend
- Manejo de bases de datos
- Desarrollo de sistemas web

## ▶️ Cómo ejecutar
1. Clonar el repositorio
2. Configurar base de datos en MySQL
3. Ejecutar en servidor local (XAMPP o similar)
